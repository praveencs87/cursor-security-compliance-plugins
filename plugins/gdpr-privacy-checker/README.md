# GDPR Privacy Checker Plugin

Comprehensive GDPR and privacy compliance checker for Cursor. Identifies PII, validates consent management, checks data retention policies, and ensures regulatory compliance.

## Features

### 🛡️ Rules
- **PII Handling** - Proper handling of personally identifiable information
- **Data Retention** - Implement retention policies and automatic deletion
- **Consent Management** - Proper consent collection and withdrawal mechanisms
- **Data Anonymization** - Anonymization and pseudonymization techniques
- **Third-Party Sharing** - Control and document data sharing

### 🔍 Skills
- **PII Detector** - Identify PII in code, databases, and logs
- **Consent Auditor** - Audit consent management implementation
- **Data Retention Checker** - Verify retention policies and deletion mechanisms

### 🤖 Agents
- **Compliance Reviewer** - GDPR compliance specialist for code reviews
- **PII Scanner** - Specialized agent for detecting and classifying PII

### ⚡ Commands
- **run-privacy-audit** - Execute comprehensive GDPR compliance audit
- **generate-data-processing-audit** - Create Article 30 records of processing activities

## Installation

Add to your `.cursorrules` or install from Cursor Marketplace.

## Usage

### Run Privacy Audit
```
@gdpr-privacy-checker run privacy audit
```

### Detect PII in Code
```
@pii-scanner find all PII in this codebase
```

### Review Compliance
```
@compliance-reviewer check GDPR compliance for this feature
```

### Audit Consent Management
```
@consent-auditor verify consent implementation
```

### Check Data Retention
```
@data-retention-checker review retention policies
```

## GDPR Coverage

This plugin helps ensure compliance with:
- **Article 5**: Data protection principles
- **Article 6**: Legal basis for processing
- **Articles 12-22**: Data subject rights
- **Article 25**: Data protection by design and default
- **Article 30**: Records of processing activities
- **Articles 33-34**: Data breach notification
- **Chapter V**: International data transfers

## Key Features

- Automated PII detection across code and databases
- Consent management validation
- Data retention policy enforcement
- Anonymization technique suggestions
- GDPR compliance scoring
- Remediation roadmaps
- Article 30 documentation generation

## Requirements

No external dependencies required. All checks are performed through code analysis.
